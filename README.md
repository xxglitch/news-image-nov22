- **Drone flattens flats near Kyiv** — a Russian strike on Dymer kills 3 and leaves rescuers searching the rubble (AP / Reuters).
- **Mercury gets a visitor** — the European-Japanese probe BepiColombo enters orbit after an eight-year voyage, with a thruster glitch reported (Reuters).
- **Factory fire in Indonesia** — 3 dead, 36 missing after a blaze at a candy plant near Jakarta (AP / Reuters).
- **Gulf shipping hit** — Houthis claim a Saudi refinery attack as tanker strikes spread near the Strait of Hormuz (Reuters).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
